# MCS Suivi

Page téléphone de suivi des régénérateurs MCS (MCS Studio).

- Données : Firebase Realtime Database, projet `mcs-atelier` (lecture et écriture réservées au compte de l'atelier).
- Depuis le téléphone : consultation, et seulement **Arrêter** (avec confirmation). Jamais de démarrage à distance.
- Page statique, sans dépendance : `index.html`. Publiée par GitHub Pages.
